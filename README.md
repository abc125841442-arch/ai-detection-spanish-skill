# ai-detection-spanish

An [Agent Skill](https://skills.sh) for detecting AI-generated text in Spanish and other non-English languages.

```
npx skills add <your-github-user>/ai-detection-spanish
```

## What it does

- **Spanish tells** — subjunctive, connectors, regional vocabulary
- **Language-agnostic heuristic** — sentence variance + cliche density
- **Cross-lingual workflow** — detect in the original language
- **Limits** — false positives on non-native writers

See [`SKILL.md`](./SKILL.md) for the full instructions.
